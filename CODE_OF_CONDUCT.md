# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
By participating you agree to uphold it.

In short: be respectful and welcoming, assume good intent, give and accept
constructive feedback gracefully, and focus on what is best for the project
and its community. Harassment, insults, personal or political attacks, and
publishing others' private information are not acceptable, in project spaces
and in public spaces when representing the project.

## Reporting

Report unacceptable behaviour to the maintainer, Huy Vu (huyvu8051 on
GitHub), by email at the address on the maintainer's GitHub profile. Please
don't use public issues for reports. All reports are reviewed promptly and
handled confidentially.

The maintainer may remove, edit or reject comments, commits, code, issues and
other contributions that violate this code of conduct, and may temporarily or
permanently ban contributors for behaviour they deem inappropriate, following
the enforcement guidelines of the Contributor Covenant.
